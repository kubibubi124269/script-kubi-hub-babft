# V5.1.1 — poprawka interfejsu ze zrzutu

Zrzut V5.1.0 pokazywał ucięte zakładki, tekst statystyk z dużą pustą przestrzenią, nieobsługiwany symbol nagłówka i długi ucięty komunikat. Dolny pasek otwierał Settings z pomiarami sesji zamiast treści komunikatu. Sprawdzenie aktualnego klienta potwierdziło poziomą listę sześciu zakładek, stałe wysokości etykiet i nierozróżniające sekcji aliasy nawigacji.

Poprawka stosuje siatkę 3×2 lub 2×3 w wąskim oknie, etykiety rosnące w pionie i wyrównane do góry oraz znaki [+]/[-]. Settings zaczyna od ustawień; pasek rozwija osobną sekcję z pełnym tekstem. DEBUG/STATS/PERFORMANCE kierują do swoich sekcji wewnątrz Settings. Oczekujące przewinięcie jest wykonywane przez harmonogram po aktualizacji układu. Raport błędów odświeża się, gdy jego sekcja jest widoczna w Settings.

Builder pokazuje informację o dostępności. Bez potwierdzonego uprawnienia serwera jego główny przycisk otwiera ręcznego asystenta. Z dostępem pokazuje BUILD i sterowanie transakcją. Wewnętrzna odmowa budowy bez uprawnionego API pozostaje aktywna. Nie zmieniono prywatnych żądań BABFT ani nie dodano obsługi jego publicznego serwera. PRO nie daje uprawnień serwera.

Weryfikacja: oficjalny kompilator Luau 0.744, 63 testy logiki, 45 sprawdzeń GUI w mocku i dwa importy rzeczywistych danych modeli — bez niepowodzeń. Sprawdzenie właściwości i geometrii układu nie jest natywnym testem renderowania. Nowej wersji nie uruchomiono w Roblox ani Studio; użytkownik musi potwierdzić wygląd na swoim urządzeniu. Loader pozostaje bez zmian.

Referencje właściwości interfejsu: [AutomaticSize](https://create.roblox.com/docs/reference/engine/classes/GuiObject#AutomaticSize), [UIGridLayout](https://create.roblox.com/docs/reference/engine/classes/UIGridLayout).
