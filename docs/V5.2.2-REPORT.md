# V5.2.2 — czytelne błędy i diagnoza START

Zrzut użytkownika pokazał ogólne powiadomienie FARM, a kolejny potwierdził komunikat „Brak uprawnionego kontrolera farmy”. Inspekcja potwierdza przyczynę: środowisko BABFT deklaruje farm=false, więc START zatrzymuje się przed uruchomieniem zadania. Nie jest to awaria wywołania Roblox ani dowód niedziałania wszystkich generatorów i ustawień.

Poprawiono powiadomienia: rzeczywista treść w okienku i dolnym pasku, kliknięcie otwiera pełny komunikat i przywraca ukryte okno. Podgląd ma limit 220 znaków Unicode; pełne błędy przycisków i zdarzeń pozostają w raporcie. Usunięto zależność zgłaszania błędu od obecności CurrentCamera. Stare połączenie kliknięcia jest odłączane przy zastąpieniu i wygaśnięciu okienka.

Farm:availability opisuje aktualną dostępność. Panel wyświetla ją przed START, a odmowa zapisuje dokładną przyczynę w ostatnim błędzie, bez tworzenia zadania, zajmowania blokady albo naliczania nieudanego cyklu.

To wydanie nie implementuje publicznej autofarmy BABFT i nie zmienia budowania ani mechaniki WORM-a. Zadano użytkownikowi pytanie o przywrócenie poprzedniej metody przenoszenia postaci, wobec wcześniejszego wymagania zgodności z zasadami gry. Brak odpowiedzi nie jest zgodą.

Weryfikacja offline: oficjalny Luau 0.744; 79 testów logiki, 69 sprawdzeń klienta i oba importy modeli. Nowe regresje obejmują dokładną przyczynę odmowy START, komunikaty Unicode, pełny wyjątek, otwarcie szczegółów z ukrytego okna, brak kamery oraz sprzątanie połączeń. Mock nie renderuje Roblox. Zrzuty użytkownika potwierdzają stan wcześniejszego wydania, nie test nowej wersji.
