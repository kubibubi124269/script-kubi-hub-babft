# Poprawki V5.1 — 2026-10-29

Punktem wyjścia był opublikowany commit V5.0 `18719c32e15cac4da011e83d4cd5838ca126943d`. Najpierw dodano testy odtwarzające błędy; pierwszy przebieg miał 40 przechodzących i 13 nieprzechodzących scenariuszy. Dopiero po ich naprawieniu dodano narzędzia dopasowania projektu. Dalsze testy obejmują również interakcje pełnego klienta.

Naprawiono:

- Numerowanie warstw: pierwsza warstwa zwykłego schematu ma 1, a nie np. 106. Wyraźne warstwy mechanicznego WORM-a pozostają zachowane.
- Eksport zawiera rzeczywisty obrót całego planu, pozycje i osie zawiasów. Import nie nakłada ponownie wcześniejszego obrotu, materiału ani odbicia.
- Walidacja zwraca komunikaty dla uszkodzonych części i BindTable. Flagi muszą być wartościami logicznymi. Plan z zawiasami nie może ukryć mechaniki pod false.
- Profil odrzuca nieznany materiał przed zmianą ustawień. Kopia zapasowa działa także po błędzie odczytu głównego pliku. Stare profile dostają neutralne wartości nowych ustawień.
- Przed budową kontrolowane są pozycje granic, nie tylko szerokość konstrukcji. Mały projekt poza działką nie przechodzi kontroli.
- Anulowanie wymaga stanu cancelled albo poprawnego committed z dokładną liczbą części. Nieznany stan nie staje się sukcesem. Nowe wybranie/budowa usuwa stary komunikat błędu.
- Szybkie importy mają odrębne identyfikatory i nie nadpisują poprzedniego projektu.
- Nowe koło korzysta z własnego materiału i pozycji. Katalog nie powiększa stale indeksu wyszukiwania po odświeżeniach. Kamera nie wymusza odtwarzania geometrii podglądu.
- Kontrolki synchronizują cofnięcie i wczytane ustawienia; pole odrzuconej wartości z getterem wraca do prawidłowej wartości. PRO wskazuje faktyczną zakładkę klucza.

Po naprawach dodano: wyśrodkowanie X/Z, przesunięcia, skalę zwykłych projektów 10–200%, dopasowanie do obszaru, kopiowanie listy materiałów i wybór numeru elementu. Dopasowanie korzysta z granic adaptera, jeśli są dostępne. W przeciwnym razie używa jawnie wpisanych wymiarów z marginesem jednego studa. Zmniejszenie i wyśrodkowanie są jedną pozycją historii UNDO. Mechaniki nie skaluje; przy przesuwaniu zawiasy przesuwają się z częściami. To narzędzia planowania — nie potwierdzenie API BABFT.

Weryfikacja: oficjalny Luau 0.744, kompilacja klienta i serwera, 61 testów logiki, 30 sprawdzeń GUI w mocku oraz 2830/960 części w dwóch importach modeli społeczności. Źródło projektu nie zmienia się przy dopasowaniu; testy obejmują obrócone granice, cofanie i zbyt mały obszar. Mock nie renderuje Roblox i nie symuluje fizyki.

Nie można potwierdzić naprawienia wszystkich możliwych błędów bez testu w Roblox. Natywnego GUI, uprawnień publicznego BABFT, fizyki WORM-a, paszczy, multiplayer i szybkości serwera nie przetestowano. Bez uprawnionego adaptera nadal dostępny jest podgląd/asystent. Nie dodano obchodzenia zabezpieczeń ani funkcji niszczenia cudzych konstrukcji. Dawne pliki modeli i stały loader pozostają zachowane.
